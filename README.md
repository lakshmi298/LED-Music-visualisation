# LED Music Visualisation

## Project Overview
LED Music Visualisation is a Digital Signal Processing (DSP)-based project that analyses music signals and represents audio variations through LED patterns using the Digilent ZedBoard (Zynq-7000 SoC).

## Technologies Used
- **MATLAB:** Audio signal processing, analysis and algorithm development.
- **Xilinx Vivado:** Hardware design and block diagram creation for system integration.
- **ZedBoard:** FPGA-based hardware implementation.

## Project Implementation
- Analysed audio signals using MATLAB.
- Designed the hardware architecture using Xilinx Vivado.
- Created a block design in Vivado to establish connections between the required hardware components.
- Implemented LED-based music visualisation using the ZedBoard FPGA.

## Key Concepts
- Digital Signal Processing
- Audio Signal Analysis
- FPGA Architecture
- Hardware-Software Integration
- System Block Design

## Hardware
